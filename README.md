**Проект "Моделирование процессов сети клиник"**

**Задача:** Автоматизация процесса записи пациентов на прием в медицинской клинике. Разработка мобильного приложения для самостоятельной записи к врачу (ранее запись осуществлялась только через администратора по телефону или при личном визите).

### Роли и результаты:

**1. Анализ существующих процессов (AS-IS):**
Провела интервью со стейкхолдерами и задокументировала текущее состояние процессов:
- [Модель BPMN AS-IS](https://github.com/AnastasyaYakebenko/-/blob/main/BPMN%20AS-IS.jpg) — описание текущего процесса записи через регистратуру.
- [Диаграмма UML State Machine (AS-IS)](Проект%203.%20Моделирование%20процессов%20сети%20клиник/UML%20State%20Machine%20Diagram.jpg) — визуализация состояний заявки пациента.

**2. Проектирование целевого процесса (TO-BE):**
Определила точки автоматизации и разработала целевую модель:
- [Модель BPMN TO-BE](Проект%203.%20Моделирование%20процессов%20сети%20клиник/BPMN%20TO-BE.jpg) — новый процесс с самостоятельной записью через приложение.
- [Интерактивный прототип мобильного приложения (Storyboard)](https://www.figma.com/proto/uOotpILtvmp2bVuyrMVMZG/Прототип-приложения-мед-клиника?node-id=203-114&t=8uGBe3CqldanjDz7-1&starting-point-node-id=203%3A114) — раскадровка основных экранов и сценариев.

**3. Разработка требований и спецификаций:**
- **User Story Mapping:** [Доска в Miro](https://miro.com/app/board/uXjVJgOGYoM=/?share_link_id=678764964196) (карта пользовательских историй, выделение MVP на основе персоны и гипотез).
- **Data Flow Diagram (DFD):** Модель потоков данных в системе (файл доступен в репозитории).
- **Use Cases и критерии приемки:** Для каждой истории из MVP разработаны сценарии и прототипы.
